# Fuente de la base de datos
Repositorio original: https://github.com/Husseinalmoadhen/StockFlow-Inventory-System
Autor: Hussein Almoadhen. Licencia MIT. Archivo original: stockflow_database.sql.
La consigna permite adaptar el modelo a cuatro entidades relacionadas. Se preservaron los conceptos products, warehouses, inventory y orders; se retiraron dependencias de ventas y se adaptó orders para registrar el traslado entre bodegas. Se añadió unicidad por producto y bodega, restricciones de dominio y función transaccional. Se diseñaron datos académicos propios.
El script original debe conservarse dentro de esta carpeta; ejecutar scripts/verificar-docker.ps1 lo obtiene de la URL oficial cuando hay conectividad.
